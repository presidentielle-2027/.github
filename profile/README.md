## Avant l’isoloir

**Présidentielle 2027 : faites le point sur vos convictions.**

Avant l’isoloir propose 80 propositions réparties sur 20 sujets, de la redistribution des richesses à l’organisation territoriale. Le bilan situe vos positions sujet par sujet et mesure votre écart avec des familles d’idées ; sous chaque sujet, des auteurs présentent les arguments des deux pôles.

Le site est indépendant, sans lien avec les pouvoirs publics ni avec les partis. Le calcul se fait dans votre navigateur, sans inscription ni consigne de vote.
